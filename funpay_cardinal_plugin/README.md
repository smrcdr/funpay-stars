# Плагин FunPay Cardinal: автовыдача Telegram Stars

Плагин работает внутри [FunPay Cardinal](https://github.com/sidor0912/FunPayCardinal) и выдаёт звёзды через сервер `stars.modelport.org` (этот репозиторий).

## Установка

1. Скопируйте `stars_autodelivery.py` в папку `plugins/` Cardinal и перезапустите Cardinal.
2. В Telegram-боте Cardinal выполните:
   ```
   /stars_url https://stars.modelport.org
   /stars_token <API_TOKEN из .env сервера>
   /stars_lots
   ```
   Сообщение с токеном бот сразу удаляет из чата. Эти же значения можно вписать вручную в `storage/plugins/5b0e9a52-8a3f-4a51-9c4e-1f7d2c6b3a90/settings.json`. Там же лежат тексты всех сообщений покупателю.
3. Откройте `https://stars.modelport.org/admin` → раздел «Лоты FunPay» и проверьте у каждого лота «★ за 1 шт.». Значение угадывается из названия: «400 звёзд» → 400. Если в названии нет числа, ставится 1, то есть «1 шт. = 1 звезда».

## Как идёт заказ

1. Покупатель оплатил лот, плагин считает `звёзды = количество × ★ за 1 шт.` (5 × 400 = 2000).
2. Username берётся из полей заказа. Плагин проверяет его через Fragment и пишет: «2000 ⭐ на @user (Имя). Username указан верно? Ответьте «да» или «нет»».
3. «да» → звёзды отправляются, покупатель получает «✅ отправлены, подтвердите заказ».
   «нет» → плагин просит username, проверяет его и снова спрашивает «верно?».
4. Если выдать не получилось (не хватает TON, сбой Fragment), покупатель видит «выдача задерживается», а вы получаете сообщение в TG. Плагин повторяет попытку каждые 5 минут, около 4 часов. Повторная оплата исключена: сервер не платит второй раз за тот же заказ.

## Автоактивация лотов

Каждые ~4 минуты плагин отправляет список лотов на сервер, а сервер отвечает, какие лоты должны быть включены. Лот включён, если TON на кошельке хватает на `★ за 1 шт. × мин. шт.` звёзд (и не меньше 50), и сессия Fragment жива. «Мин. шт.» и автоактивация настраиваются для каждого лота в админке.

В настройках Cardinal лучше выключить «Восстановление лотов» для лотов звёзд, иначе Cardinal будет включать лот, который плагин выключил из-за нехватки баланса. Плагин всё равно выключит его снова в течение нескольких минут.

## Команды TG

| Команда | Что делает |
|---|---|
| `/stars` | статус, баланс, незавершённые заказы |
| `/stars_toggle` | включить или выключить автовыдачу |
| `/stars_autolots` | включить или выключить автоактивацию лотов |
| `/stars_lots` | синхронизировать лоты сейчас |
| `/stars_retry <id>` | повторить выдачу заказа |

## Статистика

На странице `/admin`, раздел «Продажи FunPay»: выручка, себестоимость, прибыль и маржа за сегодня, 7 дней, 30 дней и всё время, а также график по дням и последние продажи.
- Себестоимость: `(цена в TON + ~0.005 TON газа) × курс TON/₽` на момент выдачи.
- Выручка: сумма заказа FunPay в ₽. Если заказ в другой валюте, она пересчитывается через курс TON. Комиссию FunPay можно вычесть переменной `FUNPAY_FEE_PCT` в `.env` сервера.
